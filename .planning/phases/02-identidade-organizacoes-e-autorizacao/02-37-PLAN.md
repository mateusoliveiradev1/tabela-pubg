`purpose=step-up`: protected start requires only a valid active authenticated session; callback persists `reauthenticated_at` for the stored actor/session.
`purpose=link-identity`: protected start additionally requires a pre-existing fresh current-method proof; callback creates a pending one-use link proof.
All actor/session values originate in `request.auth` at start and the consumed server-side transaction at callback.
Final link confirmation is not performed in this OAuth callback: it passes the still-unconsumed pending proof to the protected 02-32 path, whose sole durable writer is the 02-42 transaction.
